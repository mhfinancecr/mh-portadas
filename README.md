# mh-portadas

Generador de portadas para redes sociales de **MH Finance Costa Rica**.

Aplicación web privada (un solo archivo `index.html`, autocontenido) para crear
portadas de propiedades para publicar en Instagram, Facebook y WhatsApp.

## Características

- **Diseño Tipográfico** moderno: foto protagonista, precio grande y datos legibles.
- Formatos **Feed 1:1** (1080×1080) e **Historia 9:16** (1080×1920).
- Foto ajustable (zoom, posición, arrastre).
- Metraje discrecional: construcción y/o lote.
- Etiquetas de habitaciones/baños/parqueos en singular o plural automático.
- Contacto por WhatsApp (logo oficial).
- Generador de texto de post.
- Logo MH Finance vectorial · interfaz roja de marca.
- Ícono de app para iPhone/iPad/Mac ("Añadir a inicio").

## Despliegue (GitHub Pages)

1. Subí `index.html` y `robots.txt` a la raíz del repositorio.
2. En **Settings → Pages**, seleccioná la rama y la carpeta raíz.
3. Listo: la app queda disponible en la URL de GitHub Pages.

`index.html` es autocontenido (no requiere archivos externos salvo las fuentes de Google).
